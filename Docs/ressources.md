### **Serveur (Backend et Communication UDP)**  
**Focus Learning :**
- Comprendre le protocole **UDP** et ses applications dans les jeux en temps réel.
- Gérer les connexions multiples et la communication en temps réel avec le serveur.
- Créer un serveur de jeu évolutif et performant en **Rust**.

**Ressources :**
1. [Rust UDP Communication Example](https://doc.rust-lang.org/std/net/udp/index.html) - Exemple de communication UDP en Rust.
2. [Building a Multiplayer Game Server in Rust](https://medium.com/technical-writing-is-easy/building-a-multiplayer-game-server-in-rust-22d2d6b0622) - Guide pour construire un serveur de jeu multijoueur.
3. [Tokio Tutorial: Async Networking in Rust](https://tokio.rs/tokio/tutorial) - Tutoriel pour la gestion asynchrone des connexions réseau avec Rust.
4. [Rust Programming for Beginners](https://doc.rust-lang.org/book/) - Le livre officiel pour apprendre Rust.

### **Client Networking (Connexion et Initialisation)**  
**Focus Learning :**
- Création d’un client qui peut se connecter à un serveur **UDP**.
- Gestion des entrées utilisateur et initialisation de la connexion (IP, pseudo).
- Comprendre la communication bidirectionnelle entre le client et le serveur.

**Ressources :**
1. [How to Use UDP in Rust](https://docs.rs/async-udp/0.3.0/async_udp/) - Documentation sur l'utilisation de UDP en Rust.
2. [Handling User Input in Rust CLI](https://rust-cli.github.io/book/tutorial/index.html) - Tutoriel sur la gestion des entrées utilisateur dans une application en ligne de commande Rust.
3. [Asynchronous Rust: A Practical Introduction](https://ferrous-systems.com/blog/async-book/) - Introduction pratique à la programmation asynchrone en Rust.
4. [Command Line Applications in Rust](https://rust-cli.github.io/book/) - Guide pour créer des applications CLI en Rust.

### **Génération et Édition de Labyrinthes**  
**Focus Learning :**
- Implémenter des algorithmes de génération procédurale de labyrinthes.
- Créer un éditeur de niveaux interactif et intuitif pour le jeu.
- Comprendre la logique de génération de labyrinthes complexes et leur gestion dynamique.

**Ressources :**
1. [Maze Generation Algorithms](https://weblog.jamisbuck.org/2011/2/7/maze-generation-algorithm-recap) - Revue des algorithmes de génération de labyrinthes.
2. [Procedural Maze Generation with Rust](https://github.com/mxgmn/WaveFunctionCollapse) - Projet de génération procédurale de labyrinthes en Rust.
3. [Introduction to Rust for Game Dev](https://www.arewegameyet.rs/) - Ressources pour le développement de jeux avec Rust.
4. [How to Build a Level Editor](https://gameprogrammingpatterns.com/spatial-partition.html) - Guide pour construire un éditeur de niveaux.

### **Interface Graphique (Mini-carte et FPS)**  
**Focus Learning :**
- Créer des interfaces graphiques dans un jeu avec Rust.
- Implémenter une mini-carte dynamique qui suit les déplacements du joueur.
- Calculer et afficher le taux de frames par seconde (FPS) en temps réel.

**Ressources :**

2. [Rendering Mini-maps in 2D Games](https://gamedevelopment.tutsplus.com/tutorials/how-to-create-a-mini-map--cms-25453) - Tutoriel pour créer une mini-carte dans les jeux 2D.
3. [Game Development with ggez](https://ggez.rs/) - Framework simple pour le développement de jeux en Rust.
4. [Rendering Performance and FPS in Rust](https://nical.github.io/posts/rust-game-performance.html) - Optimisation des performances graphiques et calcul des FPS dans Rust.

### **Système de Jeu et Caméra**  
**Focus Learning :**
- Implémenter un système de déplacement dynamique du joueur.
- Gérer la caméra, avec des vues qui s'ajustent selon la position du joueur.
- Comprendre et implémenter des algorithmes de détection de collisions dans un environnement 2D.

**Ressources :**
1. [Rust Game Development Tutorials](https://www.amethyst.rs/book/latest/) - Tutoriels de développement de jeux avec Rust et Amethyst.
2. [Implementing a Player Movement System in Rust](https://dev.to/maccoda/how-to-move-players-in-games-in-rust-2l96) - Guide sur l'implémentation du système de mouvement du joueur en Rust.
3. [Camera Systems in 2D and 3D Games](https://learnopengl.com/) - Apprendre à gérer la caméra dans les jeux 2D et 3D.
4. [Collision Detection Algorithms](https://developer.mozilla.org/en-US/docs/Games/Techniques/2D_collision_detection) - Algorithmes de détection de collisions pour les jeux 2D.

### **Intelligence Artificielle et Bonus**  
**Focus Learning :**
- Développer des joueurs contrôlés par l’IA pour naviguer dans les labyrinthes (algorithmes de pathfinding).
- Implémenter des systèmes de sauvegarde et de récupération d’historiques de connexions (adresses IP, alias).
- Ajouter des éléments dynamiques comme la génération automatique de labyrinthes.

**Ressources :**
1. [Pathfinding in Games: A* Algorithm](https://www.geeksforgeeks.org/a-search-algorithm/) - Explication de l’algorithme A* pour le pathfinding.
2. [Artificial Intelligence for Maze Navigation](https://www.redblobgames.com/pathfinding/a-star/introduction.html) - Introduction à l’IA pour la navigation dans les labyrinthes.
3. [Rust JSON and Serialization](https://serde.rs/) - Utilisation de Serde pour sérialiser et désérialiser des données JSON en Rust.
4. [Building Intelligent NPCs in Games](https://gameprogrammingpatterns.com/) - Guide pour créer des PNJ intelligents dans les jeux.
